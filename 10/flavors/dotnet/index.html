dotnet MegaLinter Flavor

Description

Optimized for C, C++, C# or VB based projects

Usage

  • GitHub Action: oxsecurity/megalinter/flavors/dotnet@v10.1.0

  • Docker images:

    • GitHub Packages: ghcr.io/oxsecurity/megalinter-dotnet:v10.1.0
    • Docker Hub: docker.io/oxsecurity/megalinter-dotnet:v10.1.0
  • mega-linter-runner: mega-linter-runner --flavor dotnet
